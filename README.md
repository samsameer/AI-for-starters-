# AI for Starters

A hands-on path from "what is an agent?" to designing production agent systems like a Principal AI Architect. Updated for **October 2026**.

## Tracks

| Track | What you'll build | Start |
|---|---|---|
| [Agent Engineering](agent-engineering/) | 58 lessons: agent loops, memory, planning, frameworks, evals, security, coding-agent harnesses, product judgment, and typed decision models (TypeSafe Jev, Cloudflare Clef) | [00 · Think like a Principal AI Architect](agent-engineering/00-principal-ai-architect/) |

## Quick start

```bash
git clone https://github.com/samsameer/AI-for-starters-.git
cd AI-for-starters-
python3 agent-engineering/01-the-agent-loop/code/main.py
python3 agent-engineering/57-system-one-system-two-architecture/code/main.py
```

All lesson code runs offline with the Python 3.11+ standard library. Lessons 55–56 switch automatically to real APIs when `TYPESAFE_API_KEY` or `CLOUDFLARE_ACCOUNT_ID` and `CLOUDFLARE_AUTH_TOKEN` are set.
